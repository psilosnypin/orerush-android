# Ore Rush for Android

Ore Rush ([orerush.com](https://orerush.com)) is a 5-cart racing game on Solana where players race for $ORE.

> Ore Rush is an independent game and is **not affiliated with the ORE protocol**.

## Install

1. Download `OreRush-1.0.0.apk` from the [latest release](https://github.com/psilosnypin/orerush-android/releases/latest).
2. On your Android device, allow installing apps from unknown sources for your browser or file manager when prompted.
3. Open the APK and tap **Install**.

## Notes

This is an early build. Wallet connect inside the app may be limited; if you have trouble connecting, play at [orerush.com](https://orerush.com) in your wallet's browser.
